# Лабораторная работа №2

Структурное программирование на Python.
Дисциплина: «Методы и технологии программирования», часть 1.

Нгуен Роберт Ламович, группа 221341, вариант 5.

## Задания варианта

Средние: №5 — простые числа до 100, №7 — подсчёт гласных,
№1 — таблица умножения.

Повышенные: №6 — создание и импорт модуля, №8 — бинарный поиск.

Функции находятся в `tasks.py` и импортируются в `main.py`.

## Запуск

Нужен Python 3.11 или новее. Дополнительные библиотеки не требуются.

```bash
python main.py
```

На macOS/Linux можно использовать `python3 main.py`.
Выберите пункт меню от 1 до 4. Для выхода введите 0.

Гласные считаются в русском и английском тексте без учёта регистра.
Буква `ё` учитывается, `й` и `y` — нет.
Таблица умножения выводится для чисел от 1 до 10.

Для бинарного поиска вводится список целых чисел в неубывающем порядке.
Индекс начинается с нуля: в списке `1 3 5 7 9` число `7` имеет индекс `3`.
Если числа нет, функция возвращает `-1`. При повторах подходит любое вхождение.
Порядок списка проверяется в меню; функция принимает отсортированный список.
