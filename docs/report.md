## 1. Простые числа до 100

Функция `primes_up_to` перебирает числа от 2 до 100 включительно.
Для каждого числа проверяются делители от 2, пока квадрат делителя
не превышает проверяемое число. Если найден делитель без остатка,
цикл завершается через `break`. Блок `else` у `while` выполняется,
только если делитель не найден, и добавляет число в результат.
Число 1 не простое и не попадает в перебор.

Результат: 25 чисел, первое — 2, последнее — 97.
Для верхней границы N время работы O(N√N), дополнительная память
зависит от количества найденных простых чисел.

## 2. Подсчёт гласных

`count_vowels` переводит строку в нижний регистр, затем перебирает символы.
Счётчик увеличивается, если символ входит в строку `аеёиоуыэюяaeiou`.
Пробелы, цифры и знаки препинания на результат не влияют.

Примеры: `Ёж` → 1, `Привет, Python!` → 3, пустая строка → 0.
Время O(n), где n — длина строки. Преобразование в нижний регистр
создаёт строку длины O(n).

## 3. Таблица умножения

`multiplication_table` использует два вложенных цикла от 1 до 10.
Внешний цикл создаёт строки, внутренний добавляет произведения.
`print_table` выводит результат с выравниванием по правому краю
и подписями множителей. Например, строка 7:

```text
7 14 21 28 35 42 49 56 63 70
```

Для таблицы N × N время и память O(N²); в работе N равно 10.

## 4. Собственный модуль

Файл `tasks.py` содержит функции решения задач.
В `main.py` они подключаются через `from tasks import ...`.
Ввод и вывод находятся в `main.py`, поэтому функции можно вызывать
из тестов без запуска меню. Условие `if __name__ == "__main__"`
запускает меню только при выполнении `main.py` как программы.

## 5. Бинарный поиск

`binary_search` принимает отсортированный список и искомое число.
Переменные `left` и `right` задают границы рассматриваемого участка.
Индекс середины вычисляется как `(left + right) // 2`.
При совпадении возвращается индекс; иначе исключается левая или правая
половина. Если границы пересеклись, возвращается `-1`.

Для `[1, 3, 5, 7, 9, 11]` поиск 7 возвращает 3, поиск 8 возвращает -1.
Пустой список сразу даёт -1. При одинаковых значениях подходит любое вхождение.
Список не изменяется.

Сам поиск занимает O(log n) времени и O(1) дополнительной памяти.
Меню отдельно проверяет порядок чисел за O(n), поэтому весь путь
обработки введённого списка занимает O(n).
